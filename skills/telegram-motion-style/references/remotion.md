# Remotion workflow

## Подготовка окружения

Нужны Node.js (проверено на 24), npm, Python с Pillow/NumPy и FFmpeg/ffprobe
на PATH. Не менять глобальные зависимости или конфигурацию приложения.
Remotion/React устанавливаются только в рабочий проект. При недоступности
реестра или блокировке сети остановить зависимую установку, сообщить причину.

Из каталога навыка, подставив реальные абсолютные пути:

```sh
python3 scripts/motion.py init /path/to/work/project
cd /path/to/work/project
npm ci
```

Шаблон содержит зафиксированные версии и lockfile. В локальном проекте можно
осознанно обновить совместимые версии, затем повторить проверки и рендер.
Встроенные навыки Remotion не обязательны; текущие API проверять по официальной
документации перед расширением проекта.

## Единый план

Все времена в секундах нормализованной записи, кроме `at` внутри группы:
он отсчитывается от `origin`. `trim` использует исходную шкалу, а `prepare`
сам вычитает начало для дорожек Remotion. Координаты тапов/камеры/объектов —
window points; текст — пиксели итоговой композиции. Границы текста/звука и trim
должны попадать на кадровую сетку. Подкадровые времена контакта сохраняются.
Пути разрешаются относительно плана.

Пример структуры, а не измеренные координаты реального приложения:

```json
{
  "version": 1,
  "size": [1920, 1920],
  "fps": 60,
  "trim": [0, 6],
  "base": {
    "take": "composition-input",
    "bezel": "matching-device.png",
    "scale": 3,
    "background": "gradient",
    "muted": true
  },
  "groups": [{
    "origin": 0,
    "events": [
      {"id": "upper-detail", "type": "camera", "at": -0.75,
       "duration": 0.75, "zoom": 1.49, "focus": [201, 280],
       "curve": "reference"},
      {"id": "contact", "type": "tap", "at": 1.2, "x": 201, "y": 500},
      {"id": "heading", "type": "text", "at": 0, "duration": 3,
       "text": "Нужные фильмы\nв одном месте", "style": "gentle",
       "x": 100, "y": 80, "width": 1720, "fontSize": 64,
       "fontFamily": "Arial", "color": "#ffffff"},
      {"id": "app-sound", "type": "audio", "at": 1.4, "duration": 1,
       "src": "provided-sound.wav", "trimBefore": 0, "volume": 1}
    ]
  }]
}
```

`take` содержит нормализованный `rec.mp4`; исходный `taps.json` не изменяется.
План является источником истины: включить в него **все** контакты, камеру и слои,
которые должны попасть в этот экспорт, а не только новые. Типы `sprite`, `glint` и `swipe`
принимают свойства [старого layers.json](rendering.md),
но вместо `start` используют `at`, плюс обязательный уникальный `id`.
Это сохраняет настоящие RGBA-объекты, repair-подложку и общую проекцию камеры.

```sh
python3 /path/to/telegram-motion-style/scripts/motion.py check /path/to/plan.json
python3 /path/to/telegram-motion-style/scripts/motion.py prepare /path/to/plan.json /path/to/work/project --render-base
cd /path/to/work/project
npm test
npm run studio
```

Studio показывает существующий MP4 и отдельные дорожки текста/звука. Базовые
тапы, камера и объектные слои запечены; их правки требуют `--render-base`.
Текст/звук правятся в плане, затем `prepare` без флага: базовый файл используется
повторно только при совпадении подписи входов. Подпись учитывает запись, рамку,
подложки, извлечённые объекты и базовые события. Для обновления после изменения
самого базового движка принудительно выполнить `--render-base`.

`muted` по умолчанию true, поскольку базовый Python-рендер всегда немой.
Если запись содержит звук, явно извлечь его, сохранить trim/калибровку и добавить
`audio`-событие; подготовка сама этого не делает. Не терять звук молча и не
подменять его новой музыкой. Ведущая тишина в аудиофайле сохраняется; `at` —
позиция файла, а не обязательно слышимое начало. `trimBefore` задан в секундах.

## Экспорт

```sh
cd /path/to/work/project
npm run render -- /path/to/final.mp4
ffprobe -v error -count_frames -show_streams -of json /path/to/final.mp4
ffmpeg -v error -xerror -i /path/to/final.mp4 -f null -
```

Рендер отказывается заменять существующий выходной файл. При необходимости
`TELEGRAM_MOTION_BROWSER` задаёт абсолютный путь к установленному Chrome; иначе Remotion
может загрузить Chrome Headless Shell. Не обходить блокировки загрузки.
После рендера извлечь нужные кадры и оценить материал кольца, положение тапов,
кириллицу/emoji, переносы, завершение «Обычный» и «Эмоциональный» и возврат фокусируемого объекта.
Нельзя объявлять визуальную эквивалентность по одному прохождению unit-тестов.

Встроенная тестовая сцена генерируется командой:

```sh
python3 scripts/make_smoke.py /path/to/new-smoke-directory
```

Это синтетические цветные поля, тестовая рамка и тон, а не настоящее приложение
или официальный bezel. Она проверяет исполнение пайплайна; не заменяет проверку
на реальной записи и не является образцом художественного качества.

## Границы и источники

- Текст использует word/grapheme spans: возможны отличия kerning/лигатур от
  цельной строки; точная типографика записанного UI требует отдельных anchors.
  Зафиксировать шрифт локально для переносимого экспорта; системный Arial в
  примере и smoke — удобство локальной проверки, не обещание одинаковых метрик.
- Новые текстовые слои не движутся вместе с телефоном и не ремонтируют запись.
- Нет автоматической нарезки, определения контактов, записи симулятора или
  автоматического исправления задержек. Основной композитор сохраняется.
- Двухпроходный рендер может добавить время и повторное кодирование. При
  сравнении с исходным пайплайном оценивать стоимость и изображение на реальном
  клипе. Ускорение и pixel-perfect паритет не установлены.
